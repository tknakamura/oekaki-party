# おえかき宴会バトル

お題に合わせてスマホに指で絵を描き、みんなで投票する宴会ゲームです。各自のスマホでQRコードを読み取って参加します。

## 動かし方

```
npm install
npm start   # http://localhost:3000
```

## 環境変数

| 名前 | 内容 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 設定すると、参加者が出したお題がラウンド数より多いときに Claude が盛り上がるお題を選び、出題順と描く人へのひとことを決めます。未設定・エラー時はランダムに選びます |
| `ANTHROPIC_MODEL` | 使うモデル（省略時 `claude-haiku-5-5`） |

## ファイル

- `server.js` … ルーム・ゲーム進行（Socket.IO）
- `ai.js` … AI によるお題選定
- `prompts.js` … 内蔵のお題
- `public/` … スマホ画面
