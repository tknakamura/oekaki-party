# おえかき宴会バトル

お題に合わせてスマホに指で絵を描き、みんなで投票する宴会ゲームです。各自のスマホでQRコードを読み取って参加します。

## 動かし方

```
npm install
npm start   # http://localhost:3000
```

## 環境変数

| 名前 | 内容 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 設定すると次の AI 機能が使えます。未設定・エラー時は AI なしで動きます<br>・お題が多いときに盛り上がるお題を選ぶ／足りないときに考えて補う<br>・「AIにおまかせ」モード（幹事のテーマに合わせてお題を考える）<br>・AI審査員（絵を見て採点・コメント。2人対戦では自動で使用） |
| `ANTHROPIC_MODEL` | 使うモデル（省略時 `claude-haiku-5-5`） |

## ファイル

- `server.js` … ルーム・ゲーム進行（Socket.IO）
- `ai.js` … AI によるお題選定
- `prompts.js` … 内蔵のお題
- `public/` … スマホ画面
